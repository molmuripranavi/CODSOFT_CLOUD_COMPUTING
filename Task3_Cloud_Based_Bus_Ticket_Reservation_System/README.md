# 📖 About the Project

SmartBus Cloud is a cloud-powered Android application designed to simplify bus ticket booking and management.

Passengers can register, browse available buses, select seats, book tickets, and manage their reservations. Administrators have complete control over buses, bookings, passengers, and dashboard analytics.

The application uses **Firebase Authentication** for secure login and **Cloud Firestore** for real-time cloud data storage.

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/SmartBusCloud.git
```

### Open Project

Open Android Studio and select the cloned project.

---

### Connect Firebase

- Create a Firebase Project
- Enable Authentication
- Enable Cloud Firestore
- Download `google-services.json`
- Place it inside the **app** folder

---

### Sync Gradle

Wait until Gradle completes syncing.

---

### Run

Run the application on an Emulator or Android Device.
